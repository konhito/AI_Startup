02 / DEVELOPER FIRST

New possibilities.
Familiar interface.

Bring the SDK you already know. Set your base URL, add your key, and start making requests.

↗ OpenAI-compatible chat completions↗ Account keys you can revoke anytime↗ Token-level usage accounting
quickstart.py
from openai import OpenAI

client = OpenAI(
    base_url="YOUR_UNBOUND_URL/v1",
    api_key="YOUR_API_KEY"
)

response = client.chat.completions.create(
    model="auto",
    messages=[{
        "role": "user",
        "content": "Let's build something."
    }]
)

print(response.choices[0].message.content)
Replace the URL, model, and key with your deployment values.
